spot-the-difference

Compare two or more sets of documents. Report what differs.

Values, headings, coverage. Markdown, HTML, text, PDF, Word. Local only, nothing uploaded.

Source

Failure mode

Copy drifts during production.

Wording gets approved, then the layout changes and the file is re-rendered. What ships is not what was signed off.

Claim welcome-email.md landing-page.html Status
setup time under 10 minutes under 30 minutes DRIFT
what it is called Workspaces Projects DRIFT
plan tiers three three agree

Only the disagreements get reported. Values come first, because a changed number is rarely deliberate while reworded prose usually is.

Before it runs

Four questions.

compare

Question two changes the entire output. It is never guessed.

  1. sources two or more paths, file or folder
  2. truth is one of them authoritative, or is there no winner
  3. scope values, structure, prose, or all of them
  4. output a summary, a written report, or a to-do list

Truth named: output is directional, a to-do list for the other sources. No truth named: output stays neutral, a decision list. Three or more sources: the odd one out is named.

Two modes

Compare, and trace.

compare

What is different across these sources. Values that disagree, headings present on one side only, and what is missing where.

“Did my edits make it into the render?”

trace

Where a value or phrase still appears, file and line. Run it after a change to confirm it propagated, or after retiring wording to find the stragglers.

“Where do I still say the old price?”

The report

Four sections, in this order.

  • ValuesNumbers, dates, money, percentages. Extracted per class and masked between passes, so a price is never shredded into stray digits.
  • StructureHeadings present in one matched item and not another.
  • MissingNot found at any level, not as a file and not as a heading. Separate from items that exist on both sides but are filed differently.
  • Needs your eyeLow confidence pairings and name collisions. Guesses are labelled as guesses.

The contract

It reports. It does not fix.

  • No writesNothing is rewritten, synced, or auto-applied. Acting on a difference stays a deliberate act.
  • No verdictsWithout a source of truth it names the disagreement and stops there. Whether a wording change was an improvement is your call, never a score.
  • No silent dropsMissing optional tools are named with a count. A skipped file is always reported as skipped.
  • No uploadsEvery pass runs on the machine. There is no network call anywhere in it.
  • Real limitsMatching is by name, heading, then prefix; it does not know that “Projects” and “Selected Projects” are the same section. Values and headings are compared mechanically; prose is read, not diffed. PDF and plain text contribute no heading structure.

Install.

In Claude Code, add the marketplace and install:

/plugin marketplace add cabbagecachekid/spot-the-difference
/plugin install spot-the-difference@spot-the-difference

Or run the script directly, with no install at all:

bash spot.sh compare --source a=./docs --source b=./site --truth a

Then say this to Claude:

Compare my approved copy against what is on the site and tell me what drifted.
